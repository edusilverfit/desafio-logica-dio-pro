🦸‍♂️ Desafio Classificador de Nível de Herói

📌 Sobre o projeto

Este projeto faz parte de um desafio de lógica de programação que consiste em criar um classificador de nível de herói utilizando JavaScript.

O programa recebe o nome e a quantidade de experiência (XP) de um herói e, com base na quantidade de XP, determina seu nível.

O objetivo é praticar conceitos fundamentais da programação, como variáveis, operadores, estruturas de decisão e laços de repetição.

🎯 Objetivo

Criar um programa que armazene o nome e a experiência de um herói e classifique seu nível de acordo com a quantidade de XP acumulada.

🏆 Classificação dos níveis

Experiência (XP)	Nível

Menor ou igual a 1.000	Ferro
De 1.001 a 2.000	Bronze
De 2.001 a 5.000	Prata
De 5.001 a 7.000	Ouro
De 7.001 a 8.000	Platina
De 8.001 a 9.000	Ascendente
De 9.001 a 10.000	Imortal
Maior ou igual a 10.001	Radiante

🛠️ Tecnologias utilizadas

JavaScript — linguagem de programação utilizada no desenvolvimento do projeto.

📚 Conceitos praticados

Durante o desenvolvimento deste desafio, foram utilizados os seguintes conceitos:

Variáveis: para armazenar o nome, a quantidade de XP e o nível do herói.
Operadores: para realizar comparações entre a quantidade de XP e os limites de cada nível.
Estruturas de decisão (if/else if/else): para determinar o nível correspondente à experiência do herói.
Laços de repetição (while): para praticar estruturas de repetição.
Saída de dados (console.log): para exibir o resultado da classificação no console.

🧠 Lógica utilizada

O programa verifica a quantidade de XP do herói por meio de estruturas condicionais.

Cada condição representa um intervalo de experiência. Quando uma condição é atendida, o programa atribui o nível correspondente à variável nivel.

Por fim, o programa exibe uma mensagem com o nome do herói e o nível alcançado.
